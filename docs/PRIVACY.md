# Privacy & Child Safety (KiddyFun Code)

## Data we store

| Data | Where | Purpose |
|------|-------|---------|
| Code, missions, badges | `localStorage` on device | Learning progress |
| Optional cloud sync | Supabase (if configured) | Cross-device save |
| Speech practice counts | `localStorage` only | Encouragement stats (no audio stored) |

## What we do NOT do

- No open public chat
- No third-party ad trackers on kid pages
- No sale of children's data

## Parent / teacher

- Progress export: Teacher panel → CSV (device only)
- Parent summary: menu → Parent panel

## COPPA-inspired checklist

- [x] Minimal PII (anonymous auth default)
- [x] Parent email optional for magic link only
- [x] Local-first; cloud optional
- [ ] Formal privacy policy page (host on school site)
