KiddyFun কোড

সম্পূর্ণ গাইড — সব চিহ্ন, সব কমান্ড, সব নিয়ম

এই বই পড়ে আপনি এই ভাষায় গল্প, কুইজ, অঙ্ক, তালিকা, ফাংশন এবং গেমের সব কোড লিখতে পারবেন। এখানে কোনো কমান্ড বাদ নেই। প্রতিটি লাইনের আকার, উদাহরণ এবং নিয়ম আলাদা করে দেখানো হয়েছে।

গল্পকুইজঅঙ্কতালিকাফাংশনগেম

কোডের ভাষা ইংরেজি শব্দে লেখা হয়। ব্যাখ্যা বাংলায়। কম্পিউটার যে শব্দ বোঝে, সেই শব্দই এখানে রঙিন করে দেখানো হয়েছে।

এই বই কীভাবে পড়বেন

প্রতিটি কমান্ড তিনভাবে দেখানো হয়েছে।

আকার — লাইনটা কোন শব্দে সাজাতে হবে। নীল বাক্সে থাকে। নাম, মান, সংখ্যা এর জায়গায় আপনার নিজের শব্দ বসবে।

কালো বাক্সের কোড হুবহু চালানো যায়। রঙের মানে:

কমান্ড শব্দ"টেক্সট"সংখ্যাআপনার দেওয়া নাম# মন্তব্য
set age to 10
Rafi says "Hello!"
# এই লাইন কম্পিউটার পড়ে না
মনে রাখুন: কমান্ডের বানান ইংরেজিতে, হুবহু। set এর বদলে সেট লিখলে চলবে না। বাংলা শুধু উদ্ধৃতির ভিতরের কথায় এবং এই বইয়ের ব্যাখ্যায়।

১. এই ভাষা কী, কোথায় চলে

KiddyFun Code বাচ্চাদের জন্য বানানো একটি ইংরেজি-সদৃশ ভাষা। এক লাইনে এক কাজ। ব্লক দিয়েও একই লাইন লেখা যায়। আসল প্রোগ্রাম হলো এই লেখা। ব্লক সেই লেখারই আরেক চেহারা।

একটি ফাইল দুই রকমের একটা হতে পারে।

ধরনকী দিয়ে শুরুকী হয়
গল্পsceneচরিত্র আসে, কথা বলে, কুইজ হয়, অপেক্ষা করে। কীবোর্ড দিয়ে চরিত্র নাড়ানো যায় না।
গেমgame "নাম"তীরের চাবি বা WASD দিয়ে খেলোয়াড় চলে। কয়েন, শত্রু, জীবন, সময়।
এক ফাইলে একটাই বেছে নিন। গেম ফাইলে appears, says, narrator, choose, কুইজ বা wait চলে না। গল্পের ফাইলে move, every frame, জাম্প চলে না।

চালানোর ধাপ

  1. Code ট্যাবে লেখা খুলুন।
  2. Text মোডে লাইন লিখুন, অথবা Blocks মোডে কার্ড সাজান। দুটোই একই প্রোগ্রাম।
  3. RUN চাপুন।
  4. Output-এ মঞ্চ, কথা, কুইজের বোতাম, অথবা গেম দেখা যাবে।
  5. গেম হলে আগে মঞ্চে একবার ক্লিক করুন, তারপর চাবি চাপুন। ফোনে মঞ্চের টাচ প্যাড ব্যবহার করুন।

তীরের চাবি অথবা W A S D চরিত্র নাড়ায়। স্পেসবার জাম্প (পাশ থেকে দেখা গেমে)। কোডে চাবির নাম ইংরেজিতে লিখতে হয়: left, right, up, down, space।

২. লেখার নিয়ম

এক লাইনে এক কমান্ড

প্রতিটি কাজ নতুন লাইনে। লাইনের শেষে সেমিকোলন লাগে না।

Rafi appears
Rafi says "Hi"

টেক্সট শুধু ডবল কোটেশনে

কথার দুপাশে সোজা ডবল কোট "। সিঙ্গেল কোট ' টেক্সটের চিহ্ন নয়।

set name to "Mina"
Rafi says "Hello, Mina!"
কোট বন্ধ না করলে প্রোগ্রাম থেমে যাবে: Unclosed string। শুরুর " এবং শেষের " দুটোই লাগবে।

ব্লকের ভিতরে চার স্পেস

if, else, repeat, for each, define, every frame, when, while এর ভিতরের লাইন চার স্পেস এগিয়ে লিখুন। এক ট্যাবও চলে, ট্যাব চার স্পেসের সমান।

if score is greater than 10
    narrator says "Great score!"
end

প্রতিটি ব্লক end দিয়ে বন্ধ

যে ব্লক খোলে, তার শেষ লাইন end। else আলাদা ব্লক নয়। else তার if-এরই অংশ। তাই if আর else মিলিয়ে একটাই end।

if score is greater than 10
    narrator says "High"
else
    narrator says "Keep going"
end
else if নেই। অন্য শর্ত লাগলে else-এর ভিতরে আরেকটি if বসান। ভিতরের if-এর নিজের end থাকবে, বাইরেরটারও।
if score is greater than 10
    narrator says "High"
else
    if score equals 10
        narrator says "Exact"
    end
    narrator says "Checked"
end

উপর থেকে নিচে

কম্পিউটার প্রথম লাইন থেকে শেষ লাইনের দিকে চলে। লুপ, if, আর ফাংশন এই ধারাকে বদলায়।

বড় হাতের অক্ষর

চরিত্রের ছবির নাম বড়-ছোট হাতের অক্ষরে একই: Rafi আর rafi একই ছবি। তবু নাম প্রতিবার একইভাবে লিখুন। ভেরিয়েবল ও ফাংশনের নাম হুবহু মিলতে হবে। score আর Score এক নয়, আর Score লেখাও যাবে না কারণ কমান্ড শব্দ নাম হতে পারে না।

৭. ভেরিয়েবল এবং const

কোন অঙ্ক আগে হয়

গুণ, ভাগ, ভাগশেষ আগে। তারপর যোগ, বিয়োগ, টেক্সট জোড়া। not আর length of সবচেয়ে কাছে বাঁধে।

set total to 5 plus 3 times 2

এটা 5 + (3 × 2) = 11। (5 + 3) × 2 নয়। বন্ধনী নেই, তাই এই ক্রমই নিয়ম। দুই ধাপে লিখলে পরিষ্কার:

set part to 3 times 2
set total to 5 plus part
শূন্য দিয়ে ভাগ বা শূন্য দিয়ে ভাগশেষ করলে প্রোগ্রাম থামবে। divided by 0 লিখবেন না।

৩০. এখন নিজে লিখুন

নতুন ফাইল খুলুন। গল্প হলে scene দিয়ে শুরু করুন। গেম হলে game "আমার গেম" দিয়ে শুরু করুন। এই বইয়ের আকারের নীল শব্দের জায়গায় নিজের নাম বসান। রঙিন কমান্ড শব্দ বদলাবেন না। RUN চাপুন। ভুল এলে লাল বার্তার লাইন নম্বর দেখে সেই লাইন এই বইয়ের আকারের সাথে মিলিয়ে নিন।

এক বাক্যে পুরো ভাষা: এক লাইনে এক ইংরেজি কমান্ড, টেক্সট কোটের ভিতর, ব্লকের ভিতর চার স্পেস, ব্লকের শেষে end, if ও else মিলিয়ে একটি end, গল্প আর গেম আলাদা ফাইল।

এই গাইড KiddyFun Code-এর চলতি ভাষা অনুসারে লেখা। অ্যাপে Examples মেনুতে একই কমান্ডের তৈরি প্রোগ্রাম আছে। সেগুলো RUN করে এই বইয়ের লাইনের সাথে মিলিয়ে দেখতে পারেন।
